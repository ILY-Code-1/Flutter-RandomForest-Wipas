1. Entity Relationship Diagram (crow's foot)

Pusat model adalah Warehouse: setiap data operasional terikat ke satu gudang. Prediction dihasilkan script per tanggal dan menjadi induk ManpowerRecommendation (1:0..1), PredictionFeatureImportance, dan DecisionLog. AppUser membuat keputusan, menginput actual, mengubah konfigurasi, dan membaca notifikasi (M:N lewat NotificationRead). Atribut bertanda * wajib; <<PK>> kunci primer; <<FK>> kunci asing. Catatan: model_health.feature_importance tidak dibuat tabel tersendiri karena sama dengan bobot pada prediksi terbaru (turunan); tidak ada tabel versi model karena model_version hanya berupa label teks di skema.

2. Transformasi ERD ke LRS

KasusKeputusan transformasiTabel hasil
1:1 Warehouse–OperationalConfig, Warehouse–ModelHealth, Warehouse–DatasetStatusPK tabel anak = FK wh_id (sesuai ID dokumen {wh}).OperationalConfig, ModelHealth, DatasetStatus
1:0..1 Prediction–ManpowerRecommendation (embed manpower)Dipisah menjadi tabel dengan PK sekaligus FK pred_id; config_snapshot diratakan menjadi kolom snap_*.ManpowerRecommendation
1:N di sisi manyFK diletakkan di tabel sisi many: wh_id, pred_id, decided_by, changed_by, updated_by, actual_input_by (opsional).AppUser, DailyData, Prediction, DecisionLog, ConfigHistory, BatchLog, ModelHealthHistory, Notification
Atribut multinilai feature_importanceTabel terpisah, PK komposit (pred_id, feature_name).PredictionFeatureImportance
Atribut multinilai audience_rolesTabel terpisah, PK komposit (notif_id, role).NotificationAudience
Weak entity: old_values/new_values pada riwayat konfigurasiSatu baris per parameter yang berubah, PK komposit (history_id, field_name).ConfigHistoryDetail
M:N AppUser–Notification (status baca)Tabel junction dengan PK komposit (uid, notif_id) + read_at.NotificationRead
Map input_features (1:1, ukuran tetap)Diratakan menjadi kolom feat_* di Prediction (tidak perlu tabel).Prediction
Map manpower_final pada keputusanDiratakan menjadi *_final.DecisionLog

Notasi: + PK, # FK, - atribut; {FK} pada PK menandai PK yang juga FK.
