Desain Basis Data WIPAS (Firestore) — v1

Model dokumen NoSQL yang benar-benar dipakai aplikasi wipas-app.

Implementasi aktual WIPAS memakai Cloud Firestore (NoSQL) pada paket Spark. Script wipas-research menulis koleksi hasil batch dengan Admin SDK; aplikasi hanya menulis actual_*, decision_logs, operational_configs + config_history, dan notification_reads, dibatasi oleh firebase/firestore.rules.

1. Model NoSQL: embedding vs referencing

2. Struktur koleksi

  • (root)
    • users/{uid} — Profil & role pengguna; dibuat manual (Console/seed). Penulis: Console. Contoh ID uid-admin-7Hq2
      • display_name : string
      • email : string
      • role : string
      • wh_id : string
      • job_title : string|null
      • notification_reads/{notifId} — Status baca notifikasi per pengguna. contoh deviation_WH-CKG-01_20261009
        • read_at : timestamp
        • → referensi notifications/{notifId}
    • warehouses/{wh} — Master gudang. Penulis: Console. Contoh ID WH-CKG-01
      • name : string
      • city : string
    • daily_data/{wh}_{YYYYMMDD} — Baris Excel yang diimpor script (fitur + actual). Penulis: Script. Contoh ID WH-CKG-01_20261008
      • wh_id : string
      • date : string YYYY-MM-DD
      • day_of_week : int
      • month : int
      • is_campaign : bool
      • is_holiday : bool
      • is_payday : bool
      • pickup_request_h1 : int|null
      • projection_inbound : int
      • backlog_h1 : int|null
      • actual_inbound_h2 : int|null
      • actual_inbound_h1 : int|null
      • actual_inbound : int|null
      • source_file : string
    • predictions/pred_{wh}_{YYYYMMDD} — Hasil batch prediksi H+1 (idempoten per tanggal). Penulis: Script + Aplikasi (actual_*). Contoh ID pred_WH-CKG-01_20261009
      • wh_id : string
      • target_date : string YYYY-MM-DD
      • predicted : int
      • projection : int
      • deviation_pct : double
      • alert : bool
      • status : string
      • data_status : string
      • source : string
      • model_version : string
      • generated_at : timestamp
      • input_features : map (10 fitur)
      • feature_importance : map<string,double>
      • manpower : map
      • is_backfill : bool
      • actual_inbound : int|null
      • actual_note : string|null
      • actual_input_by : string (uid)
      • actual_input_at : timestamp
      • daily_error_pct : double|null
      • evaluated : bool
    • operational_configs/{wh} — Kapasitas & rasio manpower aktif. Penulis: Aplikasi (admin, manajer). Contoh ID WH-CKG-01
      • capacity_rider : number
      • capacity_driver : number
      • capacity_op_inbound : number
      • capacity_op_outbound : number
      • ratio_rider : number
      • ratio_driver : number
      • rounding : string
      • updated_by : string (uid)
      • updated_at : timestamp
    • config_history/{auto} — Audit trail perubahan konfigurasi (append-only). Penulis: Aplikasi (admin, manajer). Contoh ID Xk2pQ9aLm3
      • wh_id : string
      • changed_by : string (uid)
      • changed_by_name : string
      • changed_at : timestamp
      • old_values : map<string,number>
      • new_values : map<string,number>
    • decision_logs/{auto} — Keputusan manpower (append-only). Penulis: Aplikasi (admin, manajer). Contoh ID Rz8TnB4cWq
      • pred_id : string
      • wh_id : string
      • decided_by : string (uid)
      • decided_by_name : string
      • decision : string
      • manpower_final : map
      • reason : string|null
      • decided_at : timestamp
    • model_health/{wh} — Kesehatan model terkini (dihitung script). Penulis: Script. Contoh ID WH-CKG-01
      • status : string
      • rolling_mae_7d : double
      • baseline_mae : double
      • drift_threshold : double
      • model_version : string
      • mae_validation : double
      • rmse : double
      • r2 : double
      • feature_importance : map<string,double>
      • updated_at : timestamp
    • model_health_history/{wh}_{YYYYMMDD} — Riwayat Rolling MAE harian. Penulis: Script. Contoh ID WH-CKG-01_20261008
      • wh_id : string
      • date : string YYYY-MM-DD
      • rolling_mae_7d : double
      • baseline_mae : double
      • drift_threshold : double
      • status : string
    • batch_logs/{wh}_{YYYYMMDD} — Log eksekusi batch harian. Penulis: Script. Contoh ID WH-CKG-01_20261008
      • wh_id : string
      • run_date : string YYYY-MM-DD
      • target_date : string YYYY-MM-DD
      • started_at : timestamp
      • finished_at : timestamp
      • duration_sec : int
      • status : string
      • retry_count : int
      • source : string
      • message : string|null
    • dataset_status/{wh} — Ringkasan dataset hasil impor. Penulis: Script. Contoh ID WH-CKG-01
      • wh_id : string
      • last_import_at : timestamp
      • range_start : string YYYY-MM-DD
      • range_end : string YYYY-MM-DD
      • row_count : int
      • source_file : string
    • notifications/{type}_{wh}_{YYYYMMDD} — Notifikasi dalam aplikasi. Penulis: Script. Contoh ID deviation_WH-CKG-01_20261009
      • type : string
      • title : string
      • body : string
      • wh_id : string
      • target_date : string YYYY-MM-DD
      • created_at : timestamp
      • audience_roles : array<string>

Referensi antar koleksi: wh_id → warehouses; pred_id → predictions; decided_by, changed_by, updated_by, actual_input_by → users; ID notification_reads = ID notifications.
