Desain Basis Data WIPAS (Firestore) — v1

Model dokumen NoSQL yang benar-benar dipakai aplikasi wipas-app.

Implementasi aktual WIPAS memakai Cloud Firestore (NoSQL) pada paket Spark, mengikuti kontrak docs/firestore_schema.md v1.0 dari repo wipas-research. Script menulis koleksi hasil batch dengan Admin SDK; aplikasi hanya menulis field milik App: predictions.actual_*, predictions.decision_*, decision_logs, operational_configs + /history, dan notifications.read_by, dibatasi oleh firebase/firestore.rules.

1. Model NoSQL: embedding vs referencing

Referensi antar koleksi: wh_id → warehouses; prediction_id → predictions; decided_by, decision_by, changed_by, updated_by, actual_input_by, read_by[] → users; batch_log_id → batch_logs.
